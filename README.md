**Christian Monrroy**

## Tareas

| # | Tarea | Descripción |
|---|---|---|
| 01 | [Cotizador de tableros Rockwell](tarea-01-cotizador-rockwell/) | Agente ReAct que dimensiona el I/O a partir de un requerimiento en lenguaje natural, elige plataforma, detecta obsolescencia y plazos de importación incompatibles, y cotiza |
